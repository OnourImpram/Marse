# Investigation coverage and deliberate limits

Implemented. Five task-oriented navigation groups. Search before ornament. Visible proposed status and removal of the public university logo lockup. Smaller optional heritage artwork. Eight locales and Arabic RTL retained. One semantic-token stylesheet. Explicit page shell instead of regex decoration. Pure presentation copies. DOI/ISBN-first search and script-aware normalization. Cover/list catalogue views. Locale-preserved filters and selections. Source identity, inspection, scientific review, currency, language and rights shown separately. Version-bound translation manifests. Source-scoped contributor mentions. Real catalogue-composition table. Local contribution error summary with explicit not-sent output. Current CI and durable release contract. Test-count and benchmark-name restrictions replaced with general invariants and role-aware checks.

Partially implemented by design. New UI uses stable translation IDs. Existing large academic language dictionaries were not destructively migrated, but receive source and target hashes. Typed records support future identity resolution without guessing it. The provenance model records current inspection depth, not newly completed full-text review. A correction can be prepared locally, but no receiving service exists. Accessibility is tested against specified components and browser tasks, not certified by an independent human audit.

Deferred. Formal institutional approval, academic review, native-language review, code ownership licence, book-cover permission resolution, user interviews, screen-reader testing on real devices, field Core Web Vitals measurement, secure CMS and editor accounts, protected research collection, full-text search at scale, author disambiguation, method/population evidence maps, interactive knowledge graphs and 3D content.

Rejected for this release. A React or documentation-framework migration solely for appearance. Importing benchmark logos or institutional prestige. Installing a restrictive design-agent repository as public runtime. Adding Pagefind before the present small catalogue demonstrates a retrieval need unmet by the shared tested search. Cosmetic motion or WebGL. Invented reviewers, membership or clinical authority. Exporting course attachments.

The approved investigation is RESEARCH_BRIEF.md. This coverage record is the implementation interpretation of its recommended direction, not a claim that every future possibility in its benchmark matrix has been installed.
