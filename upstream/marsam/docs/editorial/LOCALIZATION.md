# Scholarly localization

The canonical layer stores source identity and shared factual structure. Locale prose is a separate edition.

Metadata such as DOI, PMID, sample size, dates and instrument item counts is not translated as prose. Consequential findings, limitations, causal language and psychometric interpretation require locale-specific review.

A source or shared brief change invalidates affected locale review. Build parity proves presence and continuity, not semantic equivalence.

The 0.11.0 roadmap additions may use English-backed draft text outside Turkish until a competent native reviewer has approved a locale edition. The interface must not label such text human reviewed.
