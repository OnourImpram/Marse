# MARSAM scholarly evidence cycle

Owner brief. The uploaded MARSAM MASTER MISSION and final strategic instruction dated 3 October 2026 authorize direct justified implementation in the existing repository. They supersede preservation of every old catalogue item. No new approval request is needed for this owner-authorized development cycle. Formal institutional and human scientific/language approvals remain separate.

Purpose. Make the existing eight-language academic portal serve the field of spirituality and mental health, with a defensible selection, explicit evidence limitations, a modest founder acknowledgement, and useful measurement resources.

Baseline. Source main 90a2e98. Public release 0.8.3. Node static generator, 27 source records, eight dossiers, eight locales, four research guides. The source tests and root build pass. Existing portal image, palette, subdued botanical ornament, Marmara academic home and five navigation groups remain.

Decisions. Add a source-backed evidence overview and structured instrument profiles to the current architecture. Retain explicit spiritually adapted CBT, group counselling and theory books after examining their actual scope. Archive two borderline self-help works outside the current scholarly catalogue because their publisher descriptions do not establish a research or professional-training contribution. Retain generic PRISMA and WHO guidance only as context for specific methods/ethics readings. No artificial publication-count target, geographic quota, field-wide map, automated clinical advice or framework migration.

Evidence model. Every current and new source has a scope decision, inspected basis and inclusion rationale. New studies have a canonical brief containing source IDs, design, population, findings, limits and permitted inference. Eight independently drafted editions derive from that brief. Each edition has its own content hash and stored brief hash. A changed brief invalidates editions until explicitly reauthored. Human review remains false. Machine parity tests check structural claims, sources, limitations and freshness, not native quality.

Discovery. Add evidence navigation, study-type/population summaries, linked topic syntheses and instrument profiles. Search includes their localized text, original names and identifiers. Keep existing ISBN/DOI handling and script-aware normalization.

Founder. A concise text section and About anchor name Prof. Dr. Halil Ekşi as founder and academic initiator on the owner's supplied authority. No director title, invented founding date, synthetic portrait or claim of formal university establishment. Link selected relevant scholarship and external official profile.

Verification. Run both build roots and current tests, execute research artifacts, exercise Chromium/Firefox/WebKit, all locales, responsive widths, Arabic bidi, Chinese search, source links and reading workflows. Include mutation tests for stale briefs, missing limitations, missing source decisions and unsupported approval. Preserve the exact approved visual asset hashes. Source changes are delivered as a review release with truthful limitations. Only MARSAM/ may change on the existing public host if deployed.
