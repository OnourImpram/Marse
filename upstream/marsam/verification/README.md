# Verification outputs

Current commands are documented in README.md and .github/workflows/verify-preview.yml. npm run check executes source contracts, generates the site and checks every internal link and source export. Run it at / and /MARSAM/.

The core, scope, layout, research, çini and scholarship browser suites use actual HTTP navigation and native browser state. BROWSERS selects Chromium, Firefox and WebKit. research_artifacts.py executes the downloadable research script and notebook and checks tampering detection.

Large per-assertion receipts and screenshots are CI artifacts. Durable release summaries belong in docs/releases. Local Playwright 1.55 results are distinguished from the matching 1.61 package/container in CI. A failed attempt is not a pass and must be explained in the execution log.

None of these checks is scientific, native-language, institutional or clinical approval, field performance measurement, or independent accessibility certification. Historical verification/live-browser.json is not a current-release receipt.
