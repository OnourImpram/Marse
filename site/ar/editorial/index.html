سياسة التحرير والمراجعة

كيف يُقترَح المحتوى ويُوثَّق ويُراجَع ويُترجَم ويُحدَّث.

ملاحظة تحريرية

نص وترجمة بمساعدة الذكاء الاصطناعي. المراجعة العلمية واللغوية النهائية لم تُنجز بعد.

إعداد مساهمة

الادعاء والمصدر في سجل واحد

يعرض كل ملف مصادره وحدود التفسير. تُفحص هوية المصدر ودعمه المباشر كلّاً على حدة. الملفات نصوص تحريرية، ولا تُقدَّم المصادر الخارجية بوصفها منشورات MARSE. يسترشد تصميم المحتوى بتمييزات IAPOS بين الادعاءات والاستشهادات واللغة والتفويض.

العملية المقترحة قبل النشر

تُعدّ المسودة، ثم تُفحص هوية المصادر ودعمها والحقوق وحداثتها، وتُراجَع المادة العلمية والترجمة منفصلتين. يوافق مسؤول على إصدار محدد. لا ترث التعديلات الجوهرية الموافقة السابقة تلقائياً. أُعدّت الترجمات بمساعدة الذكاء الاصطناعي.

الإتاحة لا تعني تلقائياً حرية إعادة الاستخدام

لا يُعاد نشر فصول الكتب أو بنود المقاييس أو الصور أو التسجيلات قبل فحص حقوق الاستخدام. تربط السجلات بالمصادر الأصلية. لا تتضمن المجموعة ملفات دراسية خاصة أو أعمالاً غير منشورة أو معلومات شخصية.

الخصوصية وإمكانية الوصول

لا توجد حسابات أو ملفات تعريف ارتباط للتتبع أو تحليلات لطرف ثالث. تُحفَظ قوائم القراءة في المتصفح فقط عندما يختار المستخدم حفظها. يستخدم البحث فهرس الموقع نفسه. للمواقع الخارجية شروطها الخاصة. تُدعَم لوحة المفاتيح ومؤشر التركيز المرئي وتقليل الحركة والتصميم المحمول. هذا ليس اعتماداً مستقلاً لإمكانية الوصول.

التصحيحات وسجل الإصدارات

تؤدي مشكلات الهوية أو التفسير أو الترجمة أو الروابط إلى مراجعة جديدة. يميّز سجل Git الإصدارات القديمة والجديدة. لا تُرقّى المواد ذات الحقوق أو الدعم غير المحسوم إلى نشر معتمد. تنشئ أداة المساهمة اقتراحاً محلياً فقط، وليست خدمة إرسال خاصة.
